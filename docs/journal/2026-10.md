## 2026-10-03 — The /build-feature POC on Roomsie T-02, and plugin 0.6.0

- **What:** `/build-feature` ran by hand on Roomsie T-02, "Scaffold the monorepo", from the grill to the merged [Roomsie PR #94](https://github.com/magentawood/roomsie/pull/94), with the `doc-architecture` guard active. This PR finalizes the stage references from the lessons, adds the "Explain this question" option, and adds learn pages.
- **What worked:**
  - Three blind reviewers. Round 1 found a real bug: the plan generator kept the previous checklist lines.
  - The predicted PR number. The ticks, the log, and the journal went into the PR before it opened.
  - The complete PR text at gate 2, and `issue-status` from `spec` to `in-review`.
- **Where the work went off track:**
  - The grill found a stale done item (the repo layout moved out of `CONTEXT.md`) and a stale product decision (the V3 prototype). The grill rules did not tell how to do this.
  - The environment took more time than the code. The problems were pnpm 12 and Corepack, the permissions of `corepack enable`, and a Docker file of root.
  - Red-green did not fit a scaffold: the code came before the tests.
  - Staged renames went into the incorrect commit. Turborepo wrote an `AGENTS.md`.
  - The reviewers did not get the spec decisions and the out-of-scope list, so they raised settled items again.
  - The user needed plain explanations for three of four open findings. A change after the last round had no review rule.
- **Prompts:** the run started with `/build-feature T-02` and followed each stage reference by hand. The user gave each decision in the `AskUserQuestion` picker, and asked for explanations in plain text.
- **Why:** [ADR-0006](../decisions/0006-poc-first-stage-references-are-drafts.md), [ADR-0024](../decisions/0024-explain-this-question.md), [ADR-0025](../decisions/0025-learn-pages.md).
- **Next:** a `/build-feature` run on a new feature, to prove the ticket stage. Each project runs `/doc-management check --sync` for `build-decision-ledger` 0.2.0 and `render-docs` 0.2.0.
